Python overview, installation and IDE setup

Estimated study time: 20 to 30 minutes · Prerequisites: none

What you will be able to do

  • Explain what Python is and name common tasks it can help automate.
  • Distinguish the Python interpreter, a code editor and an IDE.
  • Choose a setup suitable for your device and verify that it works.
  • Run a first Python command and recognise common setup errors.

1. What is Python?

Python is a general-purpose programming language. You write instructions in a readable text file, and a Python interpreter executes them. People use Python for data analysis, small utilities, workflow automation, web services, testing and scientific computing. It is not limited to one kind of application.

Core idea: Python is the language. The interpreter runs Python code. The editor helps you write it. These are related tools, but they are not the same thing.

2. Understand your workspace

  • Interpreter: the program that executes Python code.
  • Code editor: a place to write and edit source files.
  • IDE: an editor with additional development features such as run controls, debugging and project navigation.
  • Terminal: a text interface for running commands and programs.
  • Package manager: a tool such as pip that installs third-party Python packages into an environment.

3. Pick a setup that fits your device

On a Windows, macOS or Linux computer, use a supported Python 3 release from the official Python distribution and choose an editor or IDE you are comfortable with. On Android, a terminal environment such as Termux can run Python, although desktop IDE instructions do not map directly to a phone. Cloud notebooks are another option for learning, but require an internet connection and may have different package or file-system behaviour.

For desktop installation instructions, start at the official Python downloads page. For the editor, consult the official VS Code Python tutorial. Avoid installers from unknown download sites.

4. Verify the interpreter

Open a terminal and try the command appropriate to your system:

python --version
# If your system uses python3:
python3 --version

You should see a Python 3 version number. If the terminal says the command cannot be found, Python may not be installed, its executable may not be on your PATH, or your system may use a different command name. Do not install a random package to fix a missing interpreter.

5. Run your first code

Create a file named hello.py with this content:

print("Hello, Python!")
print(2 + 3)

Run it from the terminal in the directory containing the file:

python hello.py

Expected output:

Hello, Python!
5

The first line asks Python to display text. The second evaluates an addition expression and displays the result. The file is a set of instructions; running it causes those instructions to execute from top to bottom.

6. Common setup problems

  • Command not found: verify installation and the command name; reopen the terminal after changing environment settings.
  • Wrong Python version: inspect the version explicitly and ensure your editor uses the intended interpreter.
  • File not found: check the current directory and the exact filename, including the .py extension.
  • Code opens but does not run: an editor is not necessarily an interpreter. Run the file through Python or use the editor's configured run command.

7. Your practice task

Run the two-line program above, then change it so it prints your own short greeting and the result of multiplying 7 by 6. Record which command worked on your device and the version number it returned. Do not share personal paths or sensitive device information.
