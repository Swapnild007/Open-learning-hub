Lesson 01 · Foundations

What is a language model?

Objectives: Explain what an LLM is, distinguish training from inference, and predict a next word using a small Python dictionary.

Prerequisites: None. A mobile browser is sufficient for the interactive activity; the Python lab requires a Python runtime such as Termux or Pydroid.

1. From text to predictions

A language model learns patterns in token sequences. A causal language model predicts a next token using preceding context. Tokens are pieces of text and do not always correspond to whole words.

Input: The sky is
↓
Tokenizer → token IDs
↓
Neural network → next-token scores
↓
Probabilities → selected token

Repeated next-token predictions can produce paragraphs, code, and conversations. The process does not guarantee truth: a fluent answer may still be wrong.

2. Training versus inference

Training adjusts model parameters using examples and an optimization objective. Inference uses those learned parameters to predict tokens, generally without updating them. A downloaded 2.6 GB model file does not mean your phone trained it.

3. Interactive next-word experiment

These probabilities are illustrative and manually authored. This activity is not running an LLM.

The sky is ___

Choose a word to inspect its probability.

4. Hands-on Python lab

Copy this into your Android Python environment. No model download or API key is needed.

predictions = {
    "blue": 0.65,
    "clear": 0.20,
    "dark": 0.10,
    "green": 0.05
}
prompt = "The sky is"
next_word = max(predictions, key=predictions.get)
print(prompt + " " + next_word)
print("Probability:", predictions[next_word])

Expected output: The sky is blue, then Probability: 0.65.

Your task: Change the probabilities so clear becomes the highest-probability choice. Predict the output before running it.

5. Common mistakes

Do not confuse a hard-coded word selector with a trained model. Do not assume every token is a word. Do not assume the highest-probability next token must be selected: sampling can choose alternatives.
