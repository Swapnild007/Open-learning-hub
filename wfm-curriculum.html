Important: this is a workload arithmetic exercise, not an Erlang C staffing recommendation. It does not model service level, queueing, abandonment, occupancy caps, skill constraints or breaks. A real staffing model must account for these explicitly.

End-to-end capstone: Build a small contact-centre planning workflow from a clean historical dataset through forecast, interval workload, staffing assumptions, schedule coverage, intraday monitoring and a decision summary. The capstone connects the missions rather than repeating them as separate projects.
